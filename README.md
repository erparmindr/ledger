# Ledger

A private, offline-first personal finance PWA. Everything stays in your browser.

**Live:** [erparmindr.github.io/ledger](https://erparmindr.github.io/ledger/)

## Features

Transactions (expense/income/transfer/refund), multi-account, multi-currency, CSV import with auto-categorization, statement text import, recurring bills with auto-post, reconciliation with drift detection, 4-chart reports, category splitting, friend splitting with debt tracking, full backup/restore, dark/light theme, responsive, installable PWA. No accounts, no cloud, no tracking.

## Quick Start

```bash
git clone https://github.com/erparmindr/ledger.git
cd ledger
npx serve .
```

Push to `main` to deploy via GitHub Pages.
