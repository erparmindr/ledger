# Ledger Documentation

This directory contains all official product documentation for the Ledger application.

It is the authoritative source of truth for the product's vision, design system, and quality standards.

**Entry point:** start with [`Project/Documentation-Index.md`](./Project/Documentation-Index.md) — it lists every document, flags what is outdated/duplicated/missing, and declares the authoritative source for each decision type.

## Contents

| Folder | Purpose |
| --- | --- |
| `LPA/` | Ledger Product Architecture — product vision, identity, principles, and long-term direction (LPA-001 is authoritative; LPA-002–005 are reserved stubs) |
| `LPDS/` | Ledger Product Design System — UI problems register + component spec stubs (LPDS-001–015 are reserved, not yet authored) |
| `LDS/` | Ledger Design System — **the implemented design system** (LDS-Index + LDS-001–005 specs, migration tracker, milestone & sprint reports) |
| `Project/` | Project status and documentation index (health report, documentation index) |
| `QA/` | Quality assurance checklists and release quality standards |

Every future design decision and implementation must be traceable to a document in this directory.
