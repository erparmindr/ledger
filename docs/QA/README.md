# QA — Quality Assurance

This folder contains design review checklists and release quality standards.

Every UI change and every release must be checked against these documents before shipping.

## Documents

| File | Purpose |
| --- | --- |
| `UI-Review-Checklist.md` | Visual and interaction review against the LPDS and LPA-001 |
| `Accessibility-Checklist.md` | WCAG-aligned accessibility checks |
| `Release-Checklist.md` | Pre-release quality gates |
