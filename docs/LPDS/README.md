# LPDS — Ledger Product Design System

This folder defines all UI components, interaction patterns, design standards, accessibility requirements, and implementation specifications.

LPDS documents answer **how** the product is built. They are tactical and evolve with the product.

The `LPDS-000` UI Problems Register is the living backlog of UI/UX defects discovered through audits.
