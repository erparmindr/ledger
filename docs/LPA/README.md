# LPA — Ledger Product Architecture

This folder defines the product's vision, identity, principles, and long-term direction.

LPA documents answer **why** the product exists and **what** it is trying to be. They are strategic and should change rarely.

No UI, UX, or engineering decision may contradict an LPA document.
